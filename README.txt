Joshua Chidiebere Godspower — static portfolio
==============================================
Upload the entire contents of this folder to the root of your web hosting
(public_html, www, or the site root on Netlify / Vercel / GitHub Pages /
Cloudflare Pages). No build step, database or server code is required.

Structure
  index.html, about.html, projects.html, experience.html, skills.html, contact.html
  projects/<slug>.html   one case-study page per project
  css/style.css          all styling
  js/script.js           navigation, mobile menu, scroll reveals, filtering
  images/                project screenshots
  favicon.ico

Contact form
  The form on contact.html has no backend. To make it send messages, set an
  action and method on the <form> tag (see the comment just above it) using a
  service such as Formspree, Web3Forms or Netlify Forms, or your own endpoint.

Fonts are loaded from Google Fonts; the site needs an internet connection for
the exact typefaces, and falls back to system fonts otherwise.
